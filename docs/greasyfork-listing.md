# USTC评教助手

适用于中国科学技术大学教学质量管理平台 `https://tqm.ustc.edu.cn/index.html` 的**非官方评教填写辅助工具**。需要自行安装支持现代 GM API 的脚本管理器，并使用有权限的学校账号登录平台。

## 使用方法

1. 安装脚本后刷新平台页面，打开待评问卷。
2. 点击右下角“评教助手”，点击“一键速填”，再检查这门课的例外并手动提交。
3. 已经填写的答案会保留；需要重新套用模板时，在“预览与高级设置”里点击“按模板重填”。
4. 悬浮按钮可以拖动，松手后记住位置；再次打开页面会恢复。面板随入口定位，并限制在窗口内。
5. 在“预览与高级设置”中可以预览选项、清除高亮、编辑规则，也可以从脚本管理器菜单打开面板或设置。

## 开箱速填模板

首次使用已经有完整模板，无需逐题建立规则。当前适配问卷中的默认答案如下；这是便于修改的固定预设，请按实际情况检查例外。

| 题目 | 默认答案 |
| --- | --- |
| 课程、教师、助教总体评价 | 非常好 |
| 教材或讲义 | 非常好 |
| 难度、内容、进度 | 适中 |
| 上课形式 | PPT为主，板书为辅 |
| 教师需要调整或加强 | 师生交流 |
| 助教需要调整或加强 | 作业反馈 |
| 每周课外时间 | 1–2小时 |
| 具体意见或建议 | 留空 |

面板分开显示全部题目与必答题：默认模板可填 11 道选择题，其中 9 道必答，另 1 道主观建议留空。填写后显示“11/12；其中必答9/9”，避免把必答覆盖数当作全部覆盖数。已填写但未匹配规则的题目不会再被列为待补答。没有助教、没有教材、体育课等情况请自行调整相应答案。

旧版未经修改的单条默认规则会自动使用完整模板；自定义规则、禁用规则和主动清空的规则保持原样。已有自定义规则的用户可在设置中“恢复默认”来使用新模板，这会替换当前自定义规则。

## 批量提交当前任务

打开当前任务的任意一门课程问卷，点击“全部速填并提交”，即按当前规则逐教师填选并提交，确认平台显示提交成功后切换教师；本课程处理完后点击平台的“下一课程”，继续处理当前任务的课程问卷。到达最后一门后会回到当前任务的未完成列表，检查并补齐前面仍未完成的课程；支持列表分页，列表确认无未完成记录后才显示完成。已提交或只读问卷跳过，已有手动答案保留。

批量处理会执行问卷提交及相应的提交确认弹窗；请在启动前检查默认模板或自定义规则是否符合自己的意愿。面板显示正在进行的步骤、完成和跳过数量。可随时点“停止”；停止只影响后续操作，已发出的提交以平台结果为准。手动点击页面、修改问卷或从菜单打开规则设置也会停止批量处理。

遇到必答题留空、规则读取失败、平台错误、提交未确认或翻页超时会停止，不会重试提交；会等待平台原有倒计时或按钮可用（批量模式最长等待 2 分钟），不会绕过倒计时或校验。批量状态只在当前页面会话内保存，刷新或关闭页面后不会自动恢复。处理范围是当前评教任务，不会自动进入其他学期或其他任务。

## 填写与提交行为

- “一键速填”只补空白，保留已填写的单选、多选和文本；“按模板重填”会替换匹配题目的答案，多选恢复为模板指定的完整选项集合。
- 规则按顺序匹配题目关键词，支持选最高档、选项包含关键词、跳过、主观题填充文本。最高档依据常见评价词表识别，无法识别时留空；包含关键词的规则找不到对应选项时也会留空。
- **单页“一键速填”默认不提交。** 在高级设置明确勾选“本次填选后自动提交”并点击填选按钮时会尝试触发本页提交；勾选会在本次点击后复位。必答题留空、问卷切换或等待超时都会停止自动提交。最终提交状态以平台显示为准。
- 已提交问卷仅允许预览和清除高亮，不再填写。
- Enter 在非编辑区域仅填选；Backspace 在可编辑问卷中触发平台的“忽略”。输入框、规则设置、按钮及编辑区域内不触发这两个快捷操作。
- 不绕过登录、表单校验、倒计时或平台权限；批量流程需点击“全部速填并提交”启动。

## 数据与存储

脚本在当前页面读取题目、选项、必答标记、当前教师标签和表单状态，用于填选及识别问卷切换。这些页面数据只在内存处理，不发送给脚本作者，也不写入规则存储。

自定义规则和悬浮按钮位置保存在脚本管理器的 `GM.getValue` / `GM.setValue` 存储中。脚本自身不提供云同步；如果开启脚本管理器的数据同步，则由管理器及其设置处理。不要在规则里保存密码等不必要的个人信息。可在规则设置删除规则并保存，或恢复默认覆盖自定义规则。

脚本无远程答案库、远程代码、广告、统计服务或开发者后端。填写和点击提交可能使学校平台自身向其服务发送表单数据。

## 兼容与反馈

当前适配 `index__subject--*` 等问卷结构，兼容相应旧版前缀。平台改版可能导致识别失效。无法识别问卷时显示提示，不会自动替用户作答。

这是独立开发的非官方工具，不代表学校或教学质量管理平台。请自行确认相关平台规则允许此类辅助操作，并对提交的评价负责。

如遇问题，请通过反馈页说明脚本版本、浏览器及脚本管理器版本、复现步骤；截图请先遮盖姓名、账号、课程及个人评价。
