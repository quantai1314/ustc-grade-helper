# USTC评教助手 隐私政策

更新日期：2026-10-17

## 页面数据处理
本扩展在中国科学技术大学教学质量管理平台的问卷页面内读取题目、选项、必答标记、当前教师标签及表单状态，用于规则匹配、预览高亮、辅助填写和识别问卷切换。这些页面数据只在当前页面的内存中处理，不写入规则存储，也不发送给扩展开发者。

本扩展没有开发者服务器、广告、统计分析或账号注册功能；开发者不接收、出售或分享上述页面数据或你的自定义规则。

## 规则存储与浏览器同步
你在设置页配置的题目关键词、填选策略和主观题填充文本保存在浏览器的 chrome.storage.sync 中。在 Microsoft Edge 中，此存储由 Edge 管理；在 Chrome 中由 Chrome 管理。启用相应浏览器账号同步时，浏览器可能将这些规则同步到其服务及你的其他设备，具体取决于浏览器设置和服务政策。扩展开发者无法访问这项浏览器同步数据。

请避免在可同步的规则文本中保存密码、学号等不必要的个人信息。

## 查看、修改与删除
你可以在规则设置页查看和修改规则；删除自定义规则后点击保存，或使用恢复默认覆盖自定义规则。规则在修改前保留于浏览器存储中。同步副本的处理由浏览器及其账号同步机制管理。页面内临时数据随页面关闭或重新加载释放。

## 网络行为
扩展代码不主动向开发者或第三方服务器发起网络请求，不加载远程代码或资源。浏览器同步规则时可能产生浏览器自身的网络传输；在平台页面填选或提交时，平台也可能通过其自身代码向学校服务发送表单数据。本扩展不绕过平台登录、校验或等待流程。

## 权限使用
- storage：仅用于保存上述规则
- tqm.ustc.edu.cn 网站访问权限：用于在该网站的问卷页面读取上述页面状态并执行填选辅助

## 联系
如有隐私相关疑问，请通过扩展商店页面的开发者联系方式反馈。
