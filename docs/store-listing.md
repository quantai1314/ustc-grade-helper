# 商店上架文案

## 名称
USTC评教助手

## 简短描述（同 manifest，≤132 字符）
中科大教学质量管理平台评教辅助：规则化自动填选、预览确认、手动提交。

## 详细描述
还在为每学期末逐门课、逐位老师重复点选评教问卷而烦恼？USTC评教助手帮你把机械性的勾选交给规则，把最终决定权留给你。

核心功能：
• 规则化填选：内置"总体评价选最高档"等常用规则，可在设置页按题目关键词自由增删改，支持"选最高档 / 包含关键词 / 跳过 / 主观题填充文本"四种策略
• 预览确认：填选前一键高亮所有将被选中的选项，效果一目了然
• 提交控制：默认只填选，不点击提交；如需本次应用后触发提交，须在弹窗中显式勾选，平台最终结果以平台显示为准
• 未匹配提醒：列出规则未覆盖的必答题，便于人工检查

适用网站：中国科学技术大学教学质量管理平台（tqm.ustc.edu.cn）。需要用户自行使用有权限的学校账号登录。仅在问卷页面提供填选功能。此扩展为独立开发的非官方工具，不代表学校或平台。

“选最高档”根据内置常见评价词表排序；无法识别评价词时留空，不代表适合所有题型。请先预览，并根据自己的真实体验核对答案。Enter 快捷键仅填选，Backspace 在可编辑问卷中触发“忽略”；输入框、编辑区和交互控件内不触发这些快捷操作。

隐私说明：扩展在页面内处理问卷和当前教师标签以提供上述功能，不向开发者传输这些页面数据。自定义规则保存在浏览器同步存储中；启用浏览器账号同步时，浏览器可能将规则同步到其服务。扩展无自建后端、广告或统计分析，详细处理方式见隐私政策。

## 权限用途说明
- storage：保存你在设置页自定义的填选规则
- 主机权限（仅 tqm.ustc.edu.cn）：读取问卷页面结构，以便按你的规则执行填选与高亮
