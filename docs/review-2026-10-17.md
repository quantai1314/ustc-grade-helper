# 2026-10-17 审查与送审条件

后续发布方向已按用户指令改为 Greasy Fork，实际发布结果见 [用户脚本发布记录](greasyfork-release.md)。以下保留本次浏览器扩展商店审查结论。

## 结论

适合做限定网站的表单辅助扩展，但当前版本不满足“没有问题就发布”的条件，未向 Chrome Web Store 或 Microsoft Edge Add-ons 上传或送审。代码修复与商店审核通过是两个不同的判断。

## 已修复

- 自动提交改为每次 APPLY 显式传入；重新打开弹窗和快捷键均不会继承自动提交状态。
- 每次操作重新读取可见问卷；读取规则和等待提交期间核对当前问卷、教师及 DOM，检测到变化即取消。
- 多选填选检查 checked，重复应用不再取消已有目标项；禁用和只读控件不被修改。
- 选项定位使用表单标签，不再依赖固定 width 样式；已提交问卷保留只读保护。
- 评价词先取最长匹配，避免带选项前缀的否定评价被其内部肯定词错误提升。
- 主观题题干移除动态字数提示，避免填字后的正常计数变化被误判为换页。
- 规则编辑使用 DOM value，包含引号或 HTML 符号的内容能够原样保存；存储失败显示错误并保留编辑。
- 弹窗显示无问卷、只读、错误和等待状态，防止重复点击；仅提示“已触发提交”，不冒充平台已确认成功。
- 隐私说明补充页面本地处理、浏览器账号同步、平台自身网络请求以及规则管理方式。

- `test/content.test.html` 在 Chrome 的真实 DOM 中运行：15 项通过，包含只读保护、SPA切换、重复多选、文本事件、动态字数、并发、自动提交作用域、空答拦截、换教师取消等待、超时、存储失败及快捷键守卫。
- 线上已打开的已提交问卷只读核对：12 道题，现行标签和“已提交”按钮结构与选择器相符。没有修改或提交真实问卷。
- 尚未完成解压扩展后的真实 popup/content 跨上下文通信、学校平台 React 状态写入及 Edge 实机运行验证。本地 DOM 测试不能代替这些验证。
- `python tools/package.py` 可重复打包并校验 ZIP 文件与当前源码一致，ZIP 内使用 `/` 路径，仅包含运行所需目录。

## 仍需决定和准备

1. 当前默认规则预置总体评价最高档，并保留按次自动提交。Edge 政策明确限制评分评价操纵以及通过自动操作操纵平台功能；该组合存在被认定为相关自动化行为的风险。此为基于条款的判断，尚无本项目的实际审核结论。建议公开版本取消预置好评和自动提交，由用户自行定义中性填选规则，并逐次检查和手动提交。修改需同步真实代码与文案，不能只改描述。
2. Chrome 的公开政策强调单一用途、如实说明功能、最低权限和可审查性；未发现专门禁止校内评教辅助的条款，也不能据此保证接受。
3. 学校登录限制会影响审核可测试性。需提供不含真实个人数据的演示方法和审核说明；Edge 允许对无法提供测试账号作合理解释，是否充分仍由审核判断。不要交出个人学校账号。
4. 尚缺公开可访问的隐私政策 URL 和最终截图。截图不得泄露问卷夹具中的真实姓名、课程和评价；不得将演示画面描述为实际用户结果。
5. 确认学校平台本身允许相关辅助操作；本次未找到或验证其适用使用规则。
6. Chrome 商店后台被当前浏览器工具禁止脚本操控，最终上传需用户自行完成。Edge 后台可读取且已登录，但本项目没有创建条目或上传包。
